# UI styling

- Match new or changed UI to the surrounding theme, especially font family, font size, weight, and line height. Reuse existing component styles instead of browser defaults or unrelated sizes.
- Check selects, inputs, buttons, labels, and status messages in their actual container. A style scoped to a modal does not apply to the main page.
- Preserve the existing typography hierarchy: match each element to nearby elements serving the same role rather than assigning one size to all text.

# Deployment

- After completing requested changes and relevant checks, commit and push to `main` to deploy through GitHub Pages, then verify deployment. The user has requested deployment by default.
