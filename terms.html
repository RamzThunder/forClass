1. 서비스 내용

「평가 도구 모음」(이하 "이 서비스")은 교사의 평가 채점과 기록을 돕는 무료 웹 도구입니다. 별도의 회원가입 없이 사용할 수 있고, 구글 로그인을 하면 채점 기록을 사용자 본인의 구글 드라이브에 저장할 수 있습니다.

2. 사용자의 책임

  • 사용자는 입력하는 학생 정보와 채점 기록을 소속 기관의 개인정보 보호 지침에 맞게 관리해야 합니다.
  • 중요한 채점 기록은 JSON 백업 등으로 따로 보관하는 것을 권장합니다.
  • 공용 컴퓨터에서는 사용 후 로그아웃해야 합니다.

3. 보증의 제한

이 서비스는 있는 그대로 제공됩니다. 운영자는 서비스가 중단 없이 또는 오류 없이 동작함을 보증하지 않으며, 서비스 사용으로 생긴 데이터 손실이나 채점 오류에 대해 책임지지 않습니다. 최종 성적 처리 전에는 사용자가 결과를 직접 확인해야 합니다.

4. 개인정보

개인정보 처리에 관한 내용은 개인정보처리방침을 따릅니다.

5. 약관 변경과 문의

약관이 바뀌면 이 페이지에 게시합니다. 문의는 GitHub 저장소의 Issues로 남겨 주세요.
