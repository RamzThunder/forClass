개인정보처리방침

평가 도구 모음 · 시행일 2026년 10월 28일

「평가 도구 모음」(이하 "이 서비스")은 교사가 학생 평가를 채점하고 기록하도록 돕는 웹 도구입니다. 이 서비스는 별도의 서버를 운영하지 않으며, 운영자는 사용자의 채점 기록이나 개인정보를 수집·보관하지 않습니다.

1. 처리하는 정보와 저장 위치

  • 채점 기록과 학생 명렬: 사용자가 입력한 문항, 학생 명렬, 점수, 메모는 사용자의 기기(브라우저 저장소)에 저장됩니다.
  • 구글 드라이브 저장(선택): 사용자가 구글 로그인을 하면 같은 채점 기록이 사용자 본인의 구글 드라이브 「평가 도구 모음」 폴더에 JSON 파일로 저장됩니다.
  • 구글 계정 정보: 로그인한 계정의 이름과 이메일 주소를 화면에 표시하기 위해 읽으며, 사용자의 브라우저에만 보관합니다.
  • 로그인 토큰: 구글이 발급한 접근 토큰은 사용자의 브라우저에만 보관되고 약 1시간 뒤 만료됩니다.

2. 구글 사용자 데이터의 이용

이 서비스는 구글 드라이브 권한 중 이 서비스가 만든 파일에만 접근하는 권한(drive.file)만 요청합니다. 사용자의 드라이브에 있는 다른 파일은 읽거나 바꿀 수 없습니다.

구글 API로 받은 정보는 채점 기록을 저장하고 불러오는 기능에만 쓰며, 운영자를 포함한 제3자에게 전송·판매·공유하지 않고 광고에 이용하지 않습니다. 이 서비스의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

3. 보관 기간과 삭제

  • 브라우저에 저장된 정보는 사용자가 브라우저 데이터를 지우거나 채점 도구의 「전체 초기화」를 실행하면 삭제됩니다.
  • 구글 드라이브에 저장된 파일은 사용자가 드라이브에서 직접 삭제할 수 있습니다.
  • 「로그아웃」을 누르면 브라우저의 로그인 정보가 지워지고 권한이 해제됩니다. 구글 계정의 서드파티 액세스에서도 언제든 권한을 해제할 수 있습니다.

4. 학생 정보 보호

채점 기록에는 학생 이름과 점수가 포함될 수 있습니다. 사용자는 소속 기관의 개인정보 보호 지침에 따라 이 서비스를 사용해야 하며, 공용 컴퓨터에서는 사용 후 반드시 로그아웃해야 합니다.
